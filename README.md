# Simulate AWS EC2 Cost Optimization

This Python script simulates the monthly cost of an AWS EC2 instance for a backend service. It demonstrates how different strategies like right-sizing (choosing a smaller instance type) and scheduling (running only during peak hours) can significantly reduce cloud expenses compared to a continuously running, potentially over-provisioned setup. The example highlights the importance of understanding usage patterns for cost optimization.

## Language

`python`

## How to Run

1. Save the code as `cost_optimizer.py`.
2. Run from your terminal: `python cost_optimizer.py`
